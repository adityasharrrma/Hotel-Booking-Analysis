# Hotel Booking Analytics Dashboard

An end-to-end Data Analytics and Business Intelligence project that explores hotel booking patterns using Python and presents actionable business insights through an interactive Power BI dashboard.

---

## Project Overview

The hospitality industry generates large volumes of booking data that can be analysed to understand customer behaviour, identify trends, and support business decisions. This project analyses hotel booking data to uncover booking patterns, cancellation trends, customer preferences, and seasonal demand using Python and Power BI.

---

## Objectives

* Clean and preprocess hotel booking data.
* Perform exploratory data analysis (EDA).
* Generate descriptive statistical insights.
* Identify booking and cancellation trends.
* Build an interactive Power BI dashboard for business decision-making.

---

## Tech Stack

* Python
* Pandas

## Dataset

* **Source:** Kaggle
* **Dataset:** Hotel Booking Demand Dataset
* **Records:** Over 119,000 hotel booking records

## Data Cleaning

The dataset was prepared through:

* Handling missing values
* Removing duplicate records
* Correcting data types
* Creating derived features where necessary
* Preparing the data for analysis

---

## Exploratory Data Analysis

The project answers business questions such as:

* Which hotel receives the highest number of bookings?
* Which countries contribute the most bookings?
* Which months experience peak booking demand?
* How does Average Daily Rate (ADR) vary across hotels?
* Which market segments generate the highest number of bookings?
* What patterns are associated with booking cancellations?

---

## Dashboard Features

The Power BI dashboard includes:

* Total Bookings
* Cancellation Rate
* Average Daily Rate (ADR)
* Booking Trend by Month
* Country-wise Booking Distribution
* Hotel-wise Booking Analysis
* Market Segment Distribution
* Interactive Filters and Slicers

---

## Key Insights

* City Hotels recorded a higher volume of bookings than Resort Hotels.
* Booking demand exhibited clear seasonal trends.
* A limited number of countries accounted for the majority of bookings.
* Online Travel Agencies represented the largest booking source.
* Cancellation behaviour varied across hotel types and customer segments.
